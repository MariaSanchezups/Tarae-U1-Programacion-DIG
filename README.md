# Tarae-U1-Programaci-nDIG

Optimización de la Aplicación de Gestión de Contactos

Descripción de la actividad:

En esta actividad, se deberá mejorar la aplicación de Gestión de Contactos creada en la Clase 5, añadiendo nuevas funcionalidades y componentes gráficos que optimicen la experiencia del usuario y amplíen la interactividad de la interfaz gráfica.

Funciones del Código:

- Registro, edición y eliminacion de contactos
- Búsqueda de contactos en la tabla
- Estadísticas de contactos y favoritos
- Atajos de teclado y barra de progreso
- Guardado de Datos y exportación a CSV

Tecnologías usadas
- Netbeans
- Swing
- Patrón MVC
- Java

Ejecución:

Ejecutar desde Netbeans la clase main, que se encuentra en el package principal.
